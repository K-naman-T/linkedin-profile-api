How it works

The bookmarklet runs JavaScript inside your LinkedIn tab. When you call fetch() from within the page, it:

  • Carries the browser's real cookies automatically (no manual cookie extraction)
  • Uses the browser's real TLS fingerprint (no impersonation needed)
  • Participates in the browser's session graph (indistinguishable from manual browsing)
  • No Selenium, Playwright, or Puppeteer — just native browser JS

API approach (for the challenge)

The FastAPI backend uses the same approach server-side: warm-up page load → Voyager API call, with curl_cffi for Chrome TLS impersonation + full cookie jar + browser headers. The bookmarklet is the fallback if the server-side approach triggers LinkedIn's behavioral detection.
